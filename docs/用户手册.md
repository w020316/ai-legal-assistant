## 1. 项目简介

### 1.1 产品定位

linzAI 法律助手是一款面向中国法律从业者的智能法律问答与分析平台，借助大语言模型（LLM）与检索增强生成（RAG）技术，为用户提供：

- **智能法律问答**：基于法律三段论的专业法律问题解答，引用真实法条与判例
- **合同文档审查**：上传合同自动识别风险条款、缺失条款、义务时间线，输出 0-100 安全评分
- **法律文书生成**：30+ 专业模板一键生成律师函、起诉状、答辩状等法律文书
- **案例语义检索**：基于 pgvector 向量相似度检索相关案例，支持案由/法院/年份多维筛选
- **操作审计追溯**：管理员可查看全量用户操作日志，满足合规要求

### 1.2 技术架构

- **前端**：Vue 3 + TypeScript + Pinia + Element Plus
- **后端**：Spring Boot 3.4 + Spring AI 1.0 GA + MyBatis-Plus
- **存储**：PostgreSQL + pgvector + Redis
- **AI 能力**：RAG 检索增强、SSE 流式输出、双模型路由（Tacklekey 优先 + Agnes 降级）
- **部署**：Fly.io 全球边缘节点，CI/CD 自动化

### 1.3 浏览器兼容性

| 浏览器 | 最低版本 | 备注 |
|--------|----------|------|
| Chrome | 90+ | 推荐 |
| Edge | 90+ | 推荐 |
| Firefox | 88+ | 支持 |
| Safari | 14+ | 支持 |
| 移动端 Chrome/Safari | 最新版 | 响应式适配 |

## 2. 快速开始

### 2.1 注册账号

1. 访问 https://lawai-frontend.fly.dev/login
2. 点击「注册新账号」链接
3. 填写用户名（3-32 位）、密码（6-64 位）、邮箱（可选）
4. 点击「注册」按钮，注册成功后自动跳转登录页

> **说明**：注册即获得 `LAWYER` 角色权限，可使用全部业务功能。`ADMIN` 角色需由系统管理员在数据库中手动赋予。

### 2.2 登录系统

1. 在登录页输入用户名和密码
2. 点击「登录」按钮
3. 登录成功后自动跳转到「智能问答」页面
4. 系统会签发 access token（2 小时有效）和 refresh token（7 天有效），到期自动续期

### 2.3 退出登录

点击页面右上角用户头像，选择「退出登录」。系统会将当前 token 加入黑名单，确保账号安全。

## 3. 功能模块操作指南

### 3.1 智能问答

智能问答是 linzAI 的核心功能，基于 RAG 检索 + 法律三段论推理，为用户提供专业法律解答。

#### 3.1.1 新建会话

1. 点击左侧边栏的「智能问答」菜单
2. 默认会自动创建一个「新对话」会话
3. 在底部输入框输入您的法律问题，例如：「合同解除的法定条件有哪些？」
4. 点击「发送」按钮或按 `Enter` 键发送

#### 3.1.2 AI 回复机制

- **异步模式**（默认）：发送消息后立即返回，AI 在后台生成回复，页面自动轮询显示
- **流式模式**（实验性）：逐字显示 AI 回复，体验更流畅
- **自动命名**：会话标题默认为「新对话」，AI 完成首条回复后会自动生成 4-8 字摘要作为标题

#### 3.1.3 会话管理

- **会话列表**：左侧边栏显示所有会话，按更新时间倒序排列，可滚动加载
- **会话分组**：列表自动按时间分组（今天/昨天/过去 7 天/更早）
- **重命名**：点击会话标题旁的编辑图标，输入新标题
- **收藏**：点击星标图标将会话置顶
- **删除**：点击删除图标（不可恢复），支持批量勾选删除

#### 3.1.4 图片消息

1. 点击输入框左侧的图片图标
2. 选择包含法律内容的图片（支持 JPG/PNG，≤5MB）
3. AI 会先识别图片中的法律问题，再生成专业解答
4. 适用场景：合同截图、判决书照片、法律文书扫描件

#### 3.1.5 引用溯源

AI 回复中若引用了法律资料，会在回复下方显示「引用来源」卡片，包含：
- 文档标题
- 来源（如《民法典》《合同法》）
- 相关片段

### 3.2 文档分析

文档分析模块支持上传合同/协议文件，AI 自动进行结构化审查并生成报告。

#### 3.2.1 上传文档

1. 点击左侧边栏「文档分析」菜单
2. 点击上传区域或拖拽文件到上传区
3. 支持格式：PDF、DOCX、TXT、JPG、PNG
4. 单文件大小限制：25MB
5. 上传后系统自动开始分析（约 10-30 秒）

#### 3.2.2 分析报告内容

分析完成后，报告包含以下章节：

| 章节 | 内容 |
|------|------|
| 安全评分 | 0-100 分，对应 A-F 等级（90+ 低风险 / 70-89 中低 / 50-69 中高 / 0-49 高风险） |
| 大白话总览 | 150 字以内通俗说明合同核心约定与立场偏向 |
| 风险点 | 每个风险点包含：条款定位、风险等级、问题描述、修改建议、法律依据、通俗解释、财务估算、谈判优先级 |
| 缺失条款 | 合同中应包含但实际未约定的条款（如违约责任、保密条款等） |
| 义务时间线 | 各方义务及截止日期，按时间排序 |

#### 3.2.3 重新分析

如需使用最新 AI 模型重新分析，点击「重新分析」按钮。系统会清除缓存，强制重新调用 AI。

#### 3.2.4 双合同比对

1. 上传两份合同（A 和 B）
2. 在合同 A 的分析页面点击「与另一份比对」
3. 选择合同 B
4. AI 输出差异条款、风险变化方向（变好/变差/中性）和整体结论

### 3.3 文书模板

文书模板模块提供 30+ 专业法律文书模板，AI 根据用户填写的要素自动生成完整文书。

#### 3.3.1 选择模板

1. 点击左侧边栏「文书模板」菜单
2. 在左侧模板列表选择类别（如「律师函」「起诉状」「答辩状」）
3. 点击具体模板查看完整模板原文

#### 3.3.2 填写要素并生成

1. 切换到「要素填写」标签页
2. 按提示填写各要素（如当事人姓名、案由、诉求等）
3. 点击「生成文书」按钮
4. AI 根据模板和要素生成完整文书，可在右侧预览

#### 3.3.3 复制与导出

- **复制**：点击「复制全文」按钮，将生成的文书复制到剪贴板
- **导出**：点击「下载」下拉菜单，选择导出格式：
  - **Markdown**：纯文本格式，便于二次编辑
  - **Word**：.docx 格式，可直接用于正式场合
  - **PDF**：.pdf 格式，含中文字体，适合打印归档

### 3.4 案例检索

案例检索模块基于 pgvector 语义相似度，从内置案例库检索相关判例。

#### 3.4.1 关键词检索

1. 点击左侧边栏「案例检索」菜单
2. 在搜索框输入关键词（如「违约金调整」「竞业限制」）
3. 点击「搜索」按钮或按 `Enter` 键
4. 系统返回语义相关的案例列表

#### 3.4.2 多维筛选

可组合使用以下筛选条件：
- **案由**：合同纠纷、劳动争议、侵权责任、婚姻家庭、房产纠纷、借贷纠纷、知识产权、公司股权
- **法院层级**：最高院、高院、中院、基层院
- **年份**：2015 年至今

#### 3.4.3 要素示例（v1.11.0 新增）

搜索框下方提供 12 个常见法律场景的要素示例标签：
- 合同解除、违约金调整、竞业限制、工伤认定
- 精神损害赔偿、网络侵权、离婚财产分割、抚养权变更
- 房屋买卖、民间借贷、商标侵权、股东出资

点击任一标签，自动填充关键词和案由，并立即触发检索，帮助新用户快速上手。

#### 3.4.4 搜索历史（v1.11.0 新增）

- 系统自动记录最近 20 条搜索条件
- 历史以标签形式显示在搜索栏下方
- 点击历史标签可一键回填表单并重新检索
- 点击标签右侧的 × 可删除单条历史
- 点击「清空」按钮可清空全部历史

#### 3.4.5 相关案例推荐（v1.11.0 新增）

在案例详情抽屉中，底部显示最多 5 条相关案例推荐：
- 推荐算法基于案由（+3 分）、年份（+2 分）、法院（+1 分）综合评分
- 优先展示高相关性案例，不足时用其他案例补齐
- 点击推荐案例可直接切换详情，无需返回列表

#### 3.4.6 案例收藏

- 在案例列表中，悬停案例卡片，点击右上角星标按钮收藏
- 在详情抽屉中，点击「收藏」按钮也可收藏
- 点击顶部「我的收藏」按钮查看收藏夹
- 收藏夹支持：
  - **导出 Markdown**：将所有收藏导出为 .md 文件
  - **清空**：清空全部收藏（需二次确认）

> **说明**：收藏数据存储在浏览器 localStorage，仅在当前浏览器有效。更换浏览器或清除缓存后收藏会丢失。

#### 3.4.7 案例详情

点击任意案例卡片打开详情抽屉，显示：
- 案例标题
- 案由、法院、年份标签
- 来源链接（可点击跳转原始网页）
- 案件摘要
- 相关案例推荐（v1.11.0 新增）

#### 3.5.2 日志字段

| 操作类型 | LOGIN/LOGOUT/REGISTER 等 |

| 时间 | 操作时间（CST） |

### 3.6 系统状态

系统状态页面展示后端服务健康度，便于用户判断服务可用性。

## 4. 高级功能

### 4.1 多格式导出（v1.11.0 新增）

linzAI 支持将以下内容导出为 Markdown / Word / PDF 三种格式：

| 导出内容 | 入口 | 文件名规则 |
|----------|------|------------|
| 会话记录 | 智能问答 → 会话菜单 → 导出 | `linzAI会话导出_<标题>.<ext>` |
| 合同审查报告 | 文档分析 → 报告底部 → 导出 | `合同审查报告_<文件名>_<日期>.<ext>` |
| 法律文书 | 文书模板 → 生成结果 → 下载 | `<模板标题>.<ext>` |

**技术实现**：
- Markdown：前端构造 Blob 下载
- Word：后端 Apache POI 生成 .docx
- PDF：后端 Apache PDFBox 生成 .pdf，内置 Noto Sans CJK 中文字体

### 4.2 响应式适配

linzAI 全面适配桌面端、平板、移动端：

| 设备 | 断点 | 布局调整 |
|------|------|----------|
| 桌面 | ≥1024px | 完整三栏布局 |
| 平板 | 768-1024px | 侧边栏可折叠 |
| 手机 | ≤768px | 单栏布局，搜索栏垂直堆叠 |
| 小屏手机 | ≤480px | 卡片信息纵向排列 |

### 4.3 性能优化（v1.11.0 新增）

- **路由懒加载**：所有页面按需加载，首屏体积下降 40%
- **代码分割**：Vue/Element Plus/Markdown 依赖独立 chunk，缓存命中率高
- **highlight.js 按需导入**：仅加载 8 种常用语言，打包体积减少 950KB
- **Nginx Gzip 压缩**：静态资源传输体积减少 60-80%
- **AI 双模型路由**：Tacklekey 配额耗尽时自动降级到 Agnes，保证可用性

## 5. 常见问题解答

### Q1：AI 回复很慢怎么办？

**A**：AI 回复通常需要 5-30 秒。如果超过 60 秒未响应：
1. 检查网络连接
2. 刷新页面后重试
3. 系统会自动保存您的用户消息，刷新后可在会话历史中查看
4. 如长期无响应，可能是 AI 服务商限流，请稍后再试

### Q2：登录后提示「token 已过期」？

**A**：系统会自动使用 refresh token 续期。如续期失败：
1. 退出登录后重新登录
2. 清除浏览器 Cookie 后重试
3. 同一账号在多设备登录不会互踢，但建议单设备使用

### Q3：上传文档失败？

**A**：常见原因：
1. **文件格式不支持**：仅支持 PDF/DOCX/TXT/JPG/PNG
2. **文件过大**：单文件限制 25MB
3. **文件损坏**：请检查文件能否在本地正常打开
4. **文件类型伪造**：系统通过 magic bytes 校验真实文件类型，扩展名伪造会被拒绝

### Q4：导出的 PDF 中文显示为方框？

**A**：v1.11.0 已修复此问题。后端 Docker 镜像已内置 Noto Sans CJK 中文字体。如仍遇到此问题，请通过页面底部的反馈渠道联系管理员。

### Q5：案例检索结果太少？

**A**：内置案例库目前包含约 124 条案例，覆盖 8 大案由。建议：
1. 使用更宽泛的关键词（如「违约」而非「违约金过高 30%」）
2. 清除年份和法院筛选条件
3. 点击「要素示例」标签快速检索常见场景

### Q6：会话标题没有自动生成？

**A**：自动命名依赖 AI 服务。如 AI 调用失败，标题保持「新对话」。可手动点击会话标题旁的编辑图标重命名。

### Q7：管理员权限如何获取？

**A**：`ADMIN` 角色需由系统管理员在数据库中手动设置：
```sql
UPDATE sys_user SET role = 'ADMIN' WHERE username = 'your_username';
```

### Q8：数据安全如何保障？

**A**：
- 密码使用 bcrypt 加密存储，永不返回前端
- JWT token 包含黑名单机制，登出后立即失效
- 所有敏感操作记录审计日志
- 上传文件通过 magic bytes 校验，防止恶意文件
- 用户输入转义后注入 Prompt，防止 prompt injection

## 6. 故障排查

### 6.1 页面无法访问

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 502 Bad Gateway | 后端服务休眠中 | 等待 30 秒后刷新 |
| 503 Service Unavailable | 后端部署中 | 等待 1-2 分钟后重试 |
| 白屏 | 浏览器不兼容 | 使用 Chrome 90+ 或 Edge 90+ |
| 网络超时 | 网络问题 | 检查网络连接，尝试切换网络 |

### 6.2 功能异常

| 现象 | 解决方案 |
|------|----------|
| AI 回复不出现 | 刷新页面，检查会话历史 |
| 上传卡住 | 检查文件大小和格式，刷新页面重试 |
| 导出失败 | 稍后重试，或尝试其他格式 |
| 案例搜索无结果 | 调整关键词，清除筛选条件 |
